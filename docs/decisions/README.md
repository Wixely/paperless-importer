# Decision records

Create a dated record for each accepted product, architecture, security, persistence, deployment, or operational choice that would be costly or unsafe to change silently.

Use filenames such as `2026-10-09-source-disposition.md`. Each record should include status, date, context, decision, alternatives, consequences, validation, and any superseded record.
